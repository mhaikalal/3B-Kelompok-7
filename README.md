## Cara Push ke GitHub
1. Buka terminal di folder ini
2. Jalankan:
   git init
   git add .
   git commit -m "Aplikasi antrean klinik"
   git remote add origin https://github.com/nuruladzani/3B-Kelompok-7.git
   git push -u origin main
