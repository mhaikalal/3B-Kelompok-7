PENJELASAN STRUKTUR KODE PROGRAM ANTREAN KLINIK
==================================================

1. STRUKTUR DATA
----------------
- Queue (antrean) disimpan dalam $_SESSION['antrean'] sebagai array PHP.
- Setiap elemen array berisi array asosiatif: ['nomor', 'nama', 'waktu'].
- Operasi enqueue: array_push / $array[] = ... (masuk ke belakang).
- Operasi dequeue: array_shift() (keluar dari depan, FIFO).
- Linear Search: loop foreach mencari nomor antrean tertentu.

2. ALUR PROGRAM
---------------
- User mengisi nama -> klik Ambil Nomor -> data masuk queue.
- Tombol Panggil -> array_shift() menghapus data depan -> lanjut ke antrean berikutnya.
- Tombol Reset -> $_SESSION['antrean'] = [] dan nomor terpanggil = 0.
- Tombol Cari -> linear search mencari nomor dalam queue.

3. FILE PENTING
---------------
- index.php : kode utama aplikasi.
- assets/audio/ : file suara ting-ting saat panggil.

4. TEKNOLOGI
------------
- PHP (session, array sebagai queue)
- HTML + CSS (UI sederhana)
- JavaScript (Audio API untuk suara)
- Boxicons (icon)
